# 上谷游戏加速器 · 可交互原型

本包为当前设计版本的浏览器原型，不是 Android APK。默认已登录；积分、会员、网络连接和登录等交互为本地状态，刷新后重置，未接入真实 VPN、短信、广告或账号服务。

## 启动

安装 Node.js 后，在解压目录打开终端，执行：

```sh
node server.cjs
```

浏览器访问 http://127.0.0.1:4173/ 。按 Ctrl+C 停止服务器。不需要安装 npm 依赖。

端口被占用时，可在 PowerShell 执行：

```powershell
$env:PORT=4174
node server.cjs
```

然后访问 http://127.0.0.1:4174/ 。服务器仅监听本机。

## 文件

- `public/index.html`：可直接由本地服务器展示的完整页面。
- `prototype/app.html`：当前可编辑源文件，包含界面、样式和交互。
- `server.cjs`：零第三方依赖的本地服务器。
- `requirements.md`：历史需求说明，部分初版描述尚未随所有界面微调同步；当前页面和下面的交付说明优先。
- `renderer/`：源文件转独立页面的工具和配套资源。

## 修改后重新生成页面

安装 Python 3 后，在项目目录执行：

```sh
python renderer/scripts/render.py prototype/app.html public/index.html --force
```

刷新浏览器即可看到修改。图标等渲染资源可能需要联网；未包含 Node.js、Python 安装包。

## 当前确认的设计

- 导航：加速、积分会员、我的。
- 加速页默认全局；选择一款游戏即为定向加速；选择后显示配置准备过渡。底部包含活动横幅，状态提示浮动显示。
- 会员按有效期校验开启资格，到期不主动中断当前连接，断开后重新开启需要有效会员。积分与权益集中到积分会员页，该页登录后才能进入。
- 我的页右上角为设置；活动公告、分享好友为并排卡片（左图标、右文字）；下方为帮助中心、问题反馈、商务合作列表。
- 我的页底部为登录或退出按钮。已登录时按钮下方显示“上谷ID:123456/78909”，9px、50% 透明度。
- 默认账号文案为“开局必赢！恭喜您成为上谷头号玩家”；未登录提示为“登录后可以免费提速”。

此包已排除历次一次性修改脚本、过期布局草稿和测试截图，避免误执行旧脚本覆盖当前版本。
